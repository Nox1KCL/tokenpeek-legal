Privacy Policy

Effective Date: November 2026  ·  Product: TokenPeek (Chrome Extension, Manifest V3)  ·  Contact: noxielabs@gmail.com

100% Local-First Architecture — Summary

TokenPeek runs entirely inside your browser. All DOM inspection, CSS diffing, Tailwind v4 conversion, AI prompt formatting, color clustering, Design Token extraction, and Brand Styleguide PDF generation happen locally on your device. TokenPeek has no user database, no analytics, no telemetry, and no tracking. If you use the Free tier, TokenPeek makes zero outbound network requests.

1. 100% Local-First Processing

Every inspection and export feature in TokenPeek executes exclusively on your local machine inside the active Chrome tab:

  • Live DOM & Box-Model Inspection: Element hover targeting, open Shadow DOM traversal, keyboard DOM navigation, and box-model measurement run locally via an isolated Shadow DOM overlay (#tokenpeek-root).
  • Hidden about:blank Baseline CSS Diffing: Computed styles are compared locally against browser default styles from a temporary, hidden about:blank iframe and parent inherited styles, alongside same-origin document.styleSheets rules for :hover state extraction.
  • Tailwind v4 & AI Prompt Formatting: Conversion of clean CSS and component subtrees into Tailwind v4 utility classes, HTML/JSX markup, and compact AI coding prompts is performed purely via local rule-based logic — nothing is sent to any AI provider or cloud API.
  • Color Clustering & Design Token Exports: Perceptual color clustering (ΔE < 2.5), HEX/OKLCH/HSL conversions, WCAG AA/AAA contrast calculations (via culori), and exports to W3C tokens.json, Tailwind v4 @theme CSS, and Figma Variables JSON run locally in memory.
  • Client-Side Brand Styleguide PDF Generation: Vector PDF styleguides are compiled entirely inside your browser using pdf-lib and saved directly to your device. If a Pro user selects a custom PNG or JPG agency logo (up to 2 MB) for white-label PDF export, the image is read strictly in ephemeral browser memory to embed into the PDF and is never uploaded or persisted to storage.

2. Data We Do Not Collect

TokenPeek does not collect, log, store remotely, share, or transmit any of the following:

  • Webpage DOM content, text, images, stylesheets, extracted design tokens, or generated PDFs
  • Website URLs, hostnames, tab titles, or browsing history
  • Personal identifying information (name, email address, account credentials, or hardware fingerprints)
  • Browser cookies, session tokens, form inputs, or clipboard contents
  • Usage analytics, telemetry events, crash dumps, or third-party advertising trackers

5. Optional External Network Requests (Creem Pro Licensing)

TokenPeek makes no network requests at all unless you voluntarily enter a Pro license key.

  • Stateless Proxy Architecture & Background Isolation: When you activate, validate (every 24 hours), or deactivate a Pro license key, TokenPeek's Manifest V3 background service worker sends an HTTPS POST request to our minimal, stateless Cloudflare Worker proxy (/v1/activate, /v1/validate, or /v1/deactivate). The worker attaches our server-side API credential and forwards the request to Creem's License API (https://api.creem.io/v1/licenses/...). Our proxy has no database, performs no request logging, and never receives or stores webpage content, URLs, or personal data.
  • Minimal Payload: Requests transmit strictly two fields required by Creem's license lifecycle:
    • /v1/activate: your license key and an anonymous, non-personal browser label instance_name (such as Chrome · macOS · a7f3).
    • /v1/validate & /v1/deactivate: your license key and the opaque instance_id returned by Creem during activation.
    No webpage DOM, CSS, URLs, IP-linked profiles, or user account identifiers are ever sent by TokenPeek.
  • Payments & Merchant of Record (Creem): All Pro purchases, invoices, VAT/sales taxes, and refunds are processed exclusively by Creem as Merchant of Record. TokenPeek never receives, processes, or stores your payment card details or billing address. Please review Creem's Privacy Policy for details on how Creem handles purchase transaction data.
  • User-Initiated Links: Clicking checkout buttons inside the Pro modal, the optional one-time Chrome Web Store review banner, or legal documentation links simply opens the destination URL in a new browser tab at your explicit request.

6. Chrome Web Store User Data Policy & Limited Use Compliance

Limited Use Disclosure

TokenPeek's use and transfer of information received from Google APIs and Chrome Extension APIs strictly adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Specifically, TokenPeek guarantees that:

  • Access to active-tab DOM and CSS data is strictly limited to providing the user-facing CSS inspection, Tailwind v4 conversion, Design Token extraction, and local PDF export features you explicitly invoke.
  • No webpage data or browsing data is ever transferred to third parties (the sole external transmission is your voluntarily entered license key and anonymous browser instance ID sent through our stateless proxy to Creem to activate, validate, or deactivate Pro entitlement).
  • No data is ever used or sold for personalized advertising, retargeting, data brokerage, or determining creditworthiness or lending eligibility.
  • No human (including the developer) reads or receives any webpage content you inspect with TokenPeek.

7. Data Retention & How to Delete All Data

Because TokenPeek stores no user data on remote servers, you have immediate and complete control over all local extension data:

  1. Deactivate & Release Your Pro License: Open TokenPeek on any webpage, click PRO ✓ in the floating control bar, and click Deactivate on this browser. TokenPeek releases the browser slot via Creem's API and immediately wipes your stored license key and instance ID from chrome.storage.local.
  2. Delete All Local Extension Data: Open chrome://extensions, locate TokenPeek, and click Remove. Chrome immediately and permanently wipes the entire chrome.storage.local sandbox for TokenPeek (including pdfExportCount, cssCopyCount, reviewPromptDismissed, and tokenpeekLicense).
  3. Purchase & Billing Records: To access or delete billing records held by Creem, use your Creem order receipt or contact Creem under Creem's Privacy Policy.
